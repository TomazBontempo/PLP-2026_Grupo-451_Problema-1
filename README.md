# PLP - Problema 1: Sistema de Notas e Médias de Alunos

Atividade Avaliativa Final - Paradigmas de Linguagens de Programação
Universidade Veiga de Almeida - Engenharia de Software

## Como executar

```bash
python main.py
```

Escolha o paradigma no menu e siga as instruções. Ao fim de cada execução,
o programa pergunta se deseja rodar novamente ou voltar ao menu principal.

## Estrutura do projeto

```
.
├── main.py                          # Menu principal com match/case
├── estruturado/
│   └── notas.py                     # Paradigma estruturado
├── orientado_objetos/
│   ├── pessoa.py                    # Classe base Pessoa
│   ├── aluno.py                     # Subclasse Aluno + classe Turma
│   └── main.py                      # Ponto de entrada do paradigma OO
└── funcional/
    └── notas.py                     # Paradigma funcional
```
